What is ClawdTime?

ClawdTime is a computer-use agent for long tasks that FaceTimes you when stuck. Give it a task and it runs it end to end, delegating to specialist agents and tools such as Codex, Claude Code, and other apps as needed. When it needs your judgment or has a result to review, it prepares a walkthrough and FaceTimes you.

ClawdTime has its own reasoning and task engine. It handles the planning, monitoring and decisions. Specialist agents and tools do the hands-on work behind the scenes. Long-running work should continue without depending on an existing Codex chat staying active.

A FEW THINGS BEFORE WE RING.

Good questions.

Can my coding agent call me? +

ClawdTime provides an explicit attention request in a connected pilot session. The agent can request a FaceTime call when it needs input. It does not detect every blocked process or intercept every native approval. See setup requirements.

Do I need a Mac and iPhone? +

The packaged app targets Apple silicon and macOS 14 or later. It includes its runtime. Building from source requires Node 24 or later, Git and Swift 6 or later. You can use ClawdTime locally; phone features need an iMessage/FaceTime handset and line setup. Check setup requirements.

Can I share or control my screen? +

You select the Mac display and explicitly enable sharing. Computer input needs separate permission and a supported control mode. Local Stop ends ClawdTime capture and input; cancellation of a native tool already running depends on that tool. Read the screen and data details.

What happens if I don’t answer? +

A missed call is not approval. ClawdTime preserves the request outcome; it does not blindly redial or treat silence as permission to act.

Can I call or text it to start new work? +

Start work in the desktop chat. Phone and text capabilities depend on your line setup. The shared-number implementation has automated coverage but is not yet qualified for live calls. Shared inbound texting is not implemented.

Are screens and audio recorded? +

Screen frames and audio are transient, not saved as recordings. ClawdTime retains operational records needed for pairing, authorization and delivery outcomes. That is different from saying nothing is stored. See what the pilot handles.

Can I install it today? +

Yes. Version 0.4.0 includes the guided installer and Mac app for Apple silicon and macOS 14 or later. The Mac app is signed and notarized by Apple. Read the setup guide and release status before installing.
