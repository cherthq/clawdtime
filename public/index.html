A FEW THINGS BEFORE WE RING.

Good questions.

No iPhone? +

FaceTime links can be opened in a browser on Android or Windows. ClawdTime’s link-based joining flow is planned; it hasn’t been validated in this pilot yet.

Is my screen safe? +

Screen sharing is off until you enable it. You choose the display and authorize the paired session; screen access is bound to the call. Computer control requires separate permission. Local Stop, lock, sleep, or disconnect ends access. Screen frames and audio are transient, not saved as recordings.

Which agents does it work with? +

The local pilot has tested cooperative Claude Code and Codex CLI flows with simulated calls. Real handset calls are still awaiting validation. Cursor and OpenClaw integrations are coming later; existing desktop sessions aren’t automatically taken over.

Can I try a real call right now? +

This is a pilot preview. The public number, signed Mac download, and live call demo aren’t available yet. Our goal is a first call within a minute once you’re paired and connected; that timing hasn’t been measured yet.
