What is ClawdTime?

ClawdTime connects a paired coding-agent session to its human through FaceTime and iMessage. The pilot lets an agent request attention, share the selected Mac screen, and receive feedback. Setup requires an invitation, a Mac companion and explicit permissions.

Built on Chert’s communications infrastructure. Support depends on the agent and client surface; check what has been tested.

A FEW THINGS BEFORE WE RING.

Good questions.

Can my coding agent call me? +

ClawdTime provides an explicit attention request in a connected pilot session. The agent can request a FaceTime call when it needs input. It does not detect every blocked process or intercept every native approval. See the tested integrations.

Do I need a Mac and iPhone? +

The pilot requires macOS 14 or later, Node 24 or later, an operator-provided Mac companion and the intended invited iMessage/FaceTime handset. Android and Windows joining have not been validated. Check setup requirements.

Can I share or control my screen? +

You select the Mac display and explicitly enable sharing. Computer input needs separate permission and a supported control mode. Local Stop ends ClawdTime capture and input; cancellation of a native tool already running depends on that tool. Read the screen and data details.

What happens if I don’t answer? +

A missed call is not approval. ClawdTime preserves the request outcome; it does not blindly redial or treat silence as permission to act.

Can I call or text it to start new work? +

The current pilot starts with a connected agent session. General task initiation from Messages and waking arbitrary idle chats are not publicly available. New execution modes in development are separate from the deployed pilot.

Are screens and audio recorded? +

Screen frames and audio are transient, not saved as recordings. ClawdTime retains operational records needed for pairing, authorization and delivery outcomes. That is different from saying nothing is stored. See what the pilot handles.

Can I sign up today? +

Access is invitation-only. There is no public signup, public notarized Mac download or active subscription. Invited testers can follow the setup guide; everyone else can review pilot availability.
