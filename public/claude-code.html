FOR DEVELOPERS / CLAUDE CODE

Use ClawdTime with Claude Code.

ClawdTime shows your Claude Code sessions and which one waits for you. Answer a permission request from the chat. Ask it to start a coding session for a job.

Updated 28 November 2026

Set it up

  1. Install ClawdTime. Follow the setup guide.
  2. Add the hook. Run clawdtime agents hooks install --agent claude-code.
  3. See your sessions. Run clawdtime agents, or ask in the chat: “what needs me?”

What you can do

  • Approve or deny a request from the chat, the mascot's bubble or clawdtime agents approve ID.
  • Answer a question of a session: clawdtime agents answer ID 2 picks the second choice.
  • Start a coding session for a job: “fix the failing checkout test”. clawdtime jobs lists that work.

Limits

  • Claude Code shows its own prompt at the same time. The first answer wins: in ClawdTime or in the terminal.
  • A request waits in ClawdTime for 45 seconds, or 9 minutes in away mode. After that, only the terminal answers.
  • A request that ClawdTime cannot show in full is allowed only in its terminal. You can still deny it from ClawdTime.
  • The permission rules of Claude Code still apply.
