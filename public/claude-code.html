CLAUDE CODE / CONNECTOR PREVIEW

Keep Claude Code.
Add a way to reach you.

ClawdTime’s cooperative Claude Code connector lets an active session request human attention. Connector checks have passed; the full live Claude handset workflow still needs qualification.

ClawdTime team · Checked November 13, 2026

What has been tested?

The connector was checked with Claude Code 2.1.311 using synthetic multi-turn feedback. This establishes the tested connector interaction, not a completed FaceTime call, successful screen control or reconnect on a handset.

Live Claude Code calling remains unverified. Codex’s limited live evidence does not establish Claude compatibility. Your pilot contact must confirm the scope of your test.

How does the integration work?

  1. Use a trusted pilot build. Your invitation provides the setup path; there is no verified public npm installation.
  2. Connect the intended project and running session. The cooperative skill and tools bind feedback to that workflow.
  3. Request a specific review. The agent invokes an attention request when a question needs your input. Installing a skill does not automatically catch every approval or blocked process.
  4. Keep native approvals intact. Voice or text does not bypass Claude Code’s permission policy. A missed call does not authorize an action.

What are the current limits?

Physical calls, screen control and reconnect need separate Claude qualification. The shared pilot voice path takes turns, and its latency is still being improved. ClawdTime does not promise background wake-up of any idle Claude chat or unrestricted computer input.

Can I try it?

Access is invitation-only and operator-assisted. You need macOS 14+, Node 24+, an approved Mac companion and gateway, and the intended iMessage/FaceTime handset. The setup guide explains what to have ready before a supervised test.
