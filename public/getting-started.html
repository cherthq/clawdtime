One command with guided setup

The release installer targets Apple silicon and macOS 14 or later. It includes Node and the native helpers, checks the downloaded files, and starts clawdtime onboard. Setup handles your model key, permissions and optional phone pairing. Rerunning setup checks what is already ready.

Paste this command into Terminal. It installs the published runtime and opens guided setup. Read the release notes before installing. 

curl -fsSL https://www.clawdtime.com/install.sh | sh
Check published releases

Downloadable Mac app

The native app includes a setup window, secure key entry, permission guidance, a readiness view, menu-bar Start and Stop, and optional launch at login. Its bundled runtime needs no Node, Git or Xcode on the user's Mac. It targets Apple silicon and macOS 14 or later.

Early release. The Mac app is signed and notarized by Apple. Download it again if you have an earlier copy. Read the release notes for installation requirements. A published package does not establish real-call readiness.

Available today: build from source

For developers. Use macOS 14 or later, Node 24 or later with npm, Git, and Xcode command line tools with Swift 6 or later. In a new checkout, build both native helpers and start local onboarding: 

git clone https://github.com/cherthq/clawdtime.git
cd clawdtime
npm ci
npm run build
(cd mac && swift build --product ClawdTimeTaskPanel)
(cd mac && swift build --product ClawdTimeTaskCapture)
node dist/cli/main.js onboard --local

Enter your model key in the hidden prompt and grant the requested Mac permissions yourself. Local mode skips phone setup. The onboarding guide explains recovery and rerunning each step.

For shared-number development, follow the shared setup guide. It needs an enabled HTTPS coordinator and invited or existing member access. Skip dedicated-line claims. Only the paired Mac's live connection can obtain a call code; phone sign-in alone does not authorize the Mac.

Shared calls have automated coverage but remain unqualified for live use. The shared service has one simultaneous call slot. Shared inbound texting is not implemented.

Check that setup worked

Check local readiness with the guide's doctor commands. When you choose to test a call, confirm that your phone shows the selected display and that a requested action produces the intended result on your Mac. Automated checks do not prove handset audio, picture or native input success.

Use local Stop if the wrong screen appears. If a call outcome is uncertain, preserve it for recovery instead of repeatedly dialing.
