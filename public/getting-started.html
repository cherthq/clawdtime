SETUP GUIDE

Set up ClawdTime.

Choose one of two ways. Both run the same setup. You need a Mac with Apple silicon and macOS 14 or later, and a key from a model provider, such as OpenAI or Anthropic.

Version 0.4.0 · Updated 28 November 2026

Way 1: the Mac appWay 2: one commandYour first request

Way 1: the Mac app

No Terminal. Everything that ClawdTime needs is inside the app.

  1. Download ClawdTime. Download for Mac
  2. Install it. Open the downloaded file. Drag ClawdTime to Applications.
  3. Open it. Open ClawdTime from Applications. Choose Set up ClawdTime.
  4. Add your model key. Choose your provider. Paste the key in the secure field. Setup checks the key.
  5. Turn on computer use. Say yes when setup asks.
  6. Give two permissions. Choose Open System Settings. In Accessibility, turn on ClawdTime. In Screen Recording, turn on ClawdTime. Come back to setup. It checks again.
  7. Finish. Choose Finish. The mascot appears on your desktop.

On macOS 15 and later, the Screen Recording list is named Screen & System Audio Recording. Skip for now is on every step. The last screen says what a skipped step leaves undone.

Way 2: one command

For Terminal users. It installs ClawdTime for you only and never uses sudo. You do not need Node, Git or Xcode.

  1. Open Terminal. It is in Applications, Utilities.
  2. Paste this command and press Return.
    $ 
    curl -fsSL https://www.clawdtime.com/install.sh | sh
    It checks every file before it installs it.
  3. Add the command to your PATH, if asked. The installer can print one line that does this. Run that line.
  4. Answer the setup questions. Setup starts in the same window. Type your model key at the hidden prompt. Say yes to computer use.
  5. Give two permissions. In System Settings, Privacy & Security, turn on Terminal in Accessibility and in Screen Recording. Then choose Check again.
  6. Finish. The mascot appears on your desktop. To start ClawdTime later, run clawdtime start.

When you use another terminal app, such as iTerm, turn on that app instead of Terminal.

Your first request

Click the mascot to open the chat. Type a request, for example:

Open Wikipedia and tell me today's featured article.

ClawdTime opens the page, reads it and answers in the chat. An orange cursor shows each move. To stop it, press Stop in the bar at the top of the screen, or hold Escape.

To speak instead of typing, press Talk. Voice uses an OpenAI key, set as OPENAI_API_KEY when ClawdTime starts. Typing works with every provider.

When a step is not ready

Run setup again. In the app, open Settings > General, and choose Run setup again. In Terminal, run clawdtime onboard. Each step checks what is ready and continues from where it stopped.

In Terminal, clawdtime computer doctor lists each part and says what is missing.

Update

The app: download it again and replace ClawdTime in Applications. The command: run the same command again. Your settings and keys stay.

macOS asks for the two permissions again after an update. Setup checks this and tells you.

Uninstall

In the app, open Settings > General, and choose Uninstall ClawdTime. In Terminal, run clawdtime uninstall. It lists what it moves to the Trash and asks first. It deletes nothing.

Phone calls (preview)

ClawdTime can call your phone when a task needs you, and you can call it on FaceTime. Today this needs the source install and a phone line from Chert. Follow the phone line guide.

Build from source

For developers. You need Node 24 or later, Git, and Swift 6 or later (the Xcode command line tools). The installer checks each one. 

curl -fsSL https://www.clawdtime.com/install.sh | sh -s -- --source

Read INSTALL.md for each step.
