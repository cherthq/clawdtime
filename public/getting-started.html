GETTING STARTED / PUBLIC GUIDE

A guided start.
Your existing tools.

Install ClawdTime with the Mac app or one command, then follow the guided setup. This page explains prerequisites; it does not activate your Mac or place a call.

ClawdTime team · Checked November 13, 2026

Before you begin

  • A phone with FaceTime and iMessage.
  • A Mac with Apple silicon, running macOS 14 or later.
  • ClawdTime, from the Mac app or the install command.
  • A supported, running coding session and the project you intend to connect.
  • A display you are comfortable sharing, with private material closed or hidden.

Get ClawdTime only from this site or its GitHub releases. Do not download a similarly named package.

Set up

  1. Install ClawdTime and run the guided setup. Download for Mac and open the app, or paste the install command into Terminal. The setup asks for your model key and each permission.
  2. Give the setup prompt to the intended coding session. Your agent guides configuration while preserving its native permissions.
  3. Select the screen and grant permission locally. Screen Recording is needed for viewing. Accessibility and separate control consent are needed for supported computer input. View-only is a valid choice.
  4. Enable the companion locally. Check the selected display and session in the Mac Control Panel. Being connected is not itself permission to share.
  5. Authorize one supervised test call. Confirm the correct screen, response delivery and continuation. If the call fails or has an unknown outcome, do not repeatedly redial.

How do I know setup worked?

A successful installation or connected call is only a milestone. In the supervised test, check that the phone shows the intended screen, your feedback reaches the intended agent, and the agent actually continues the agreed work. A computer input being submitted is not proof that the intended UI changed.

Local Stop ends ClawdTime sharing and input. End the call when finished. Use Stop if the wrong screen, session or device appears.
