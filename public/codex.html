Use ClawdTime with Codex.

ClawdTime shows your Codex sessions and which one waits for you. Answer an approval request from the chat. Ask it to start a coding session for a job.

Updated 28 November 2026

Set it up

  1. Install ClawdTime. Follow the setup guide.
  2. Add the hook. Run clawdtime agents hooks install --agent codex. It adds its own entries to ~/.codex/hooks.json and changes no other hook.
  3. Trust the hook in Codex. Open Codex and run /hooks once.
  4. See your sessions. Run clawdtime agents, or ask in the chat: “what needs me?”

What you can do

  • Approve or deny a request from the chat, the mascot's bubble or clawdtime agents approve ID.
  • Start a coding session for a job: “fix the failing checkout test”. clawdtime jobs lists that work.
  • Bring the terminal of a session to the front: clawdtime agents focus NAME.

Limits

  • Without the hook, a Codex session that waits for approval shows as Working.
  • A request that ClawdTime cannot show in full is allowed only in its terminal. You can still deny it from ClawdTime.
  • The approval rules of Codex still apply.
  • Removal: clawdtime agents hooks uninstall --agent codex removes only these entries.
