ClawdTime can bring a question and the selected Mac screen from a running Codex session to your phone. The current pilot has limited live evidence; it is not a general remote-control or idle-chat service.

ClawdTime team · Checked November 13, 2026

What has been tested?

Codex desktop

Screen sharing and spoken feedback have been observed in a running desktop chat. A limited native-control task has also been observed. These results apply to the tested workflow, not every desktop tool or client version.

The desktop app version was not recorded. Reconnect, longer calls, broader control and conversational latency remain open checks.

Codex CLI

Codex CLI 0.166.0-alpha.5.1 passed synthetic connector checks. Synthetic feedback confirms connector behavior; it does not prove a real handset call or screen-control session.

Ask your pilot contact which installed build and client surface your invitation covers.

How does a call fit into my work?

  1. Keep the intended Codex session running. Connect that project using the trusted pilot integration.
  2. Request attention explicitly. Ask the agent to call when a specific decision or visual review would help. The skill does not detect every blocked process.
  3. Review the selected screen. Respond by voice or text. Voice currently takes turns and can have noticeable delays.
  4. Continue in the authorized workflow. Native approvals still apply. Sharing does not grant unrestricted computer control.

Does it take over an idle Codex chat?

No. The current workflow needs a running, connected session. A separate managed execution mode is in development; it is not the same chat and is not the deployed pilot described here.

Before you try it

You need an invitation, macOS 14+, Node 24+, the operator-provided companion and gateway, and your intended iMessage/FaceTime handset. Screen selection and local permission are explicit. Public npm installation and notarized downloads are not ready.
